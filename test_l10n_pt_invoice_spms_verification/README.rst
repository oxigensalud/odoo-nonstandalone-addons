This module is not meant to be used. It holds the automated tests of
``l10n_pt_invoice_spms_verification`` that need modules it does not
depend on: the certified Portuguese invoicing (``ptplus``) and its debit
notes (``ptplus_account_debit_note``).

The other tests are in ``l10n_pt_invoice_spms_verification`` itself.
